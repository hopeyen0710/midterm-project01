# 時空密室

依據 `BRIEF.md` 製作的互動網站雛形。玩家從 11:30 進入城堡，依序經過鋼琴、日記、畫像、人偶與午夜五關，走向「下一位旁白」結局。

## 本機開啟

需要 Python 3。於專案根目錄執行：

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

以瀏覽器開啟 <http://127.0.0.1:4173>。網站使用原生 HTML、CSS 與 JavaScript，無需安裝前端套件；請使用 HTTP 伺服器開啟，避免直接雙擊 HTML 導致模組無法載入。

## 已建立的架構

- 城堡開場、五關章節導覽、旁白、道具欄與循環結局。
- 音樂盒順序輸入、項鍊拖曳／按鈕濾鏡、畫像碎片交換與翻面、齒輪與心跳節奏實驗、午夜事件排序。
- 關卡解鎖、錯誤提示、重新開始確認、此裝置的進度儲存。
- 手機與桌面排版、鍵盤操作、降低驚嚇與可切換音效。

## 示範規則

原始簡介未指定具體答案。本版採以下示範設定，均集中於 `dist/game-data.js`，可依正式劇本替換：

1. 鋼琴：依序輸入 `1 → 3 → 2 → 4`。
2. 日記：使用紅玻璃項鍊，顯示示範指令並取得畫室鑰匙。
3. 畫像：選取兩片以交換，排成 `1、2、3、4` 後翻面。
4. 人偶：裝上三個齒輪，將節奏設為每分鐘 `60` 次，驗證王冠轉移。
5. 午夜：`11:58` 啟動機械心跳，`11:59` 將王冠移至人偶，`00:00` 由人偶承受命運。

故事時間隨關卡推進，沒有真實倒數。音效預設關閉、降低驚嚇預設開啟。進度儲存在瀏覽器 localStorage，沒有跨裝置同步；無法存取儲存空間時會顯示提示。
