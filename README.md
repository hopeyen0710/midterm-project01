# 時空密室｜午夜之前

一款單人 3D 密室逃脫遊戲。探索城堡、閱讀線索，透過對話與解謎，找出被封存的真相。

## 劇情介紹

晚上 23:30，你帶著艾琳的求救信，來到一座城堡。大門旁，名叫伊恩的青年叫住了你；城堡裡，一場尚未結束的典禮正困住艾琳。

午夜逐漸逼近。你必須走進音樂室、畫廊與工坊，留意物件和文件中的線索，為艾琳尋找離開的路。

## 如何開啟遊戲

請使用有鍵盤、滑鼠的電腦，並以支援 WebGL 2 的瀏覽器開啟。

1. 回到 [專案首頁](https://github.com/hopeyen0710/midterm-project01)，點選綠色的 **Code → Download ZIP**，下載遊戲。
2. 將下載的 ZIP 完整解壓縮，打開其中的 `game` 資料夾。
3. 雙擊 `index.html`，用瀏覽器開啟遊戲。
4. 填寫你的稱呼（留白會使用「訪客」），按下「進入城堡」。
5. 閱讀求救信，依畫面提示回應伊恩，展開探索。

遊戲可以離線遊玩，不需要安裝其他套件或啟動伺服器。GitHub 上的檔案預覽頁不能直接遊玩，請先下載並解壓縮。

## 基本操作

| 操作 | 功能 |
| --- | --- |
| W／A／S／D | 向前／向左／向後／向右移動 |
| 滑鼠 | 點一下場景後，移動滑鼠環視；未鎖定滑鼠時，也可按住左鍵拖曳環視 |
| F | 與準星對準的物件互動，例如開門、閱讀紙條或與角色交談 |
| Esc | 釋放滑鼠游標，方便點選上方功能按鈕 |
| 點選畫面按鈕 | 選擇回答、翻閱文件或操作謎題 |
| 滑鼠滾輪 | 捲動較長的文件內容 |

例如：走近一扇木門，將畫面中央的準星對準門，再按 **F** 即可開關。若無法互動，試著再靠近一點，並確認中間沒有其他物件擋住。

閱讀文件或對話時，移動會暫停；關閉面板或讀完劇情後即可繼續探索。部分長文需要捲到最下方，才能按「讀完，繼續」。若滑鼠沒有恢復環視，再點一下場景即可。

## 探索時的小幫手

- **隨身紀錄**：重看已發現的文件、物品與對話。
- **探索提示**：不知道下一步怎麼做時，點選查看提示；需要更多方向可再按「再給一個提示」。
- **聲音按鈕**：啟用或切換遊戲聲音。沒有聲音時，先點選「啟用聲音」。
- **操作說明**：隨時查看按鍵功能。
- **重新開始**：確認後清除本次進度，從開場重新遊玩。

## 遊玩前須知

- 目前版本可探索城堡，體驗音樂室與畫廊等已開放內容；完整五關與結局尚未開放。
- 進度只保留在目前開啟的頁面。返回遊戲首頁後再進入可接續；**重新整理或關閉頁面會失去進度**，尚無自動存檔功能。
- 若出現無法顯示 3D 場景的提示，請確認瀏覽器支援 WebGL 2 並已啟用硬體加速，再按「重新嘗試」。
