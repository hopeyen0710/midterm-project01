# 時空密室

使用 Three.js、HTML、CSS、JavaScript 製作的單人 3D 密室逃脫遊戲。

## 開啟遊戲

直接雙擊 [game/index.html](game/index.html)。這是內嵌 JavaScript、CSS 與目前所需 Three.js 程式的單一 HTML，可以離線開啟，也可單獨複製到其他位置。
遊玩不需要 Node.js、pnpm、本地伺服器或安裝套件。

## 目前進度

2026-11-03：已套用使用者選定的 A「華麗王室」美術方向：黑藍大理石、酒紅絨布、古金壁板、尖拱、燭光吊燈與冷月光。音樂室使用開蓋鋼琴，畫廊使用國王／艾琳／伊恩油畫與精細雕花框，工坊有雕花木櫃、象牙白展示人偶與胸口發條心臟示意。原本14個互動入口、三扇門與可行走區保留；主要家具的碰撞範圍依替換模型同步調整。

依使用者後續選擇，主要物件已改用14種現成精細CC0模型，包括雕花家具、吊燈、燭臺、畫框、雕像、鋼琴、落地鐘、人物及人偶。模型不是A圖的客製資產，因此造型、人物面貌與髮型仍有差異。

這是可自由走動的場景探索版；完整五關謎題與終典演出尚未開放。艾琳已加入原模型頂點的程序化起身、僵住與坐回動畫，並非骨架動畫。原始概念圖作為美術方向，並非實際遊戲截圖。

本輪依 plan.v2.md 完成至第 22 步的已確認範圍，第二關可完成並前往第三關畫廊入口。開啟 game/index.html，可填寫稱呼（留白使用「訪客」），再按「進入城堡」。黑畫面會逐漸浮現泛黃求救信與雨聲。收好信件後，伊恩會問「你是……從外面來的人？」。

三個回答各有指定回覆：「我收到艾琳的信。」及「你是誰？」在讀完回覆後開門；選「……」會得到提醒，可重新回答，門維持關閉。開門後可直接使用 WASD 沿石階向前入室，大門在身後關上，雨聲轉為室內環境聲。若先關閉提問面板，可靠近大門按 F 再回應。故事時間維持 23:30。

按「看看大廳」接續艾琳對話、兩次離開高臺的嘗試、典禮冊翻頁與承諾三選項。三種承諾都通往鋼琴探索，沒有選錯懲罰。人物演出使用原模型頂點的程序化起身、抬髖、雙手下放、僵住及坐回動畫，並非骨架步行動畫。

沿西側走廊，對準木門按 F 進入音樂室。琴架上兩張紙條可分別按 F 查看；音樂盒在鋼琴左側矮架上，打開可觀察八格。已讀線索會收錄於隨身紀錄。對準鋼琴按 F 開啟琴鍵，左右捲動可找到月亮、鳥、花、王冠；其餘為一般黑白琴鍵。

輸入「月亮 → 鳥 → 花 → 王冠」會顯示艾琳的末兩音提示，可按「再試一次」重試。「月亮 → 鳥 → 王冠 → 花」可直接辨識為正解，不必先猜錯。正解後依序自動演奏、顯示艾琳台詞、滑開 3D 暗格；拿起紅玻璃吊墜、閱讀說明並聽完後續三段對話後，直接進入第二關並切換為 23:40，自動傳送至大廳門口面向艾琳，不再停留於第一關完成畫面。

第二關使用「背景漸暗 → 旁白／對話 → 閱讀後繼續」呈現液體、人物與機關事件。可選四種阻流方式；正解是「轉動緊急分流閥門，並用銅蓋封堵主管道」。三種錯誤均可重試，沒有真實倒數、血量或道具消耗。正確結果讀完後記錄液體改道、銀杯乾燥，接續典禮冊將命令改為「座椅」的對話，時間保持 23:40。改令對話結束後自動恢復探索，不直接開啟典禮冊調查面板或顯示查看典禮冊的任務；玩家找到書桌、對準典禮冊按 F 翻閱後，才顯示調查選項與相關任務。選「暫時返回探索」後，可到大廳銀杯前按 F 重開選項。

對準典禮冊按 F 可選普通翻閱或使用紅玻璃。普通閱讀不推進調查；透視讀完已知印記、約束規則與畫廊線索後，接續燭臺引導。宴會長桌靠大廳入口的桌端設置四根獨立儀式燭臺，由左到右以銀杯、王冠、座椅、報時鐘的純圖形牌辨識，牌面不含文字與數字；對準任一根按 F 開啟試驗。只有第 3 根「座椅」重燃能驗證有效命令；其他選項可重試，也可直接選正解。典禮冊書桌已加寬、加深，完整承托冊子與銀杯，碰撞範圍同步更新。

讀完附件指引後畫廊門開啟，第二關完成時間為 23:45。可選繼續逗留或帶艾琳前進；逗留保留進度，前進後以漸暗文字交代入場，將玩家放到畫廊安全位置，艾琳模型保留在大廳原位。第三關僅有入口，尚未實作畫像謎題。

## 修改程式後更新 HTML

修改 `game/main.js`、`game/styles.css` 或 `game/page-template.html` 後，在專案根目錄執行：

```powershell
cd game
pnpm install --frozen-lockfile
pnpm build
pnpm test:data
```

打包更新 `game/index.html`，不會啟動伺服器。請修改原始碼後打包，避免直接修改產出的 HTML 被下次打包覆蓋。
開發工具：Node.js（本次使用 24.22.1）、pnpm 11.25.0、esbuild 0.28.2。

Codex Windows 內建環境若無全域 pnpm，可在 `game/` 內使用：

```powershell
$projectPnpm = Join-Path $env:USERPROFILE '.cache\codex-runtimes\codex-primary-runtime\dependencies\bin\fallback\pnpm.cmd'
& $projectPnpm install --frozen-lockfile
& $projectPnpm build
& $projectPnpm test:data
```

## 目前的瀏覽器回歸測試

在專案根目錄執行 `node tests/check-stage2.cjs`，或在 game/ 執行 `pnpm test:browser`；預設驗證步驟 22，僅列 T7／T8 的 19 案，T1～T6 不執行。狀態與門鎖檢查使用 `node tests/check-stage2-state.mjs` 或 `pnpm test:state`。需要 Playwright 與已安裝 Chrome；可透過 `PLAYWRIGHT_MODULE_PATH` 指定 Playwright 套件目錄，未在遊戲加入瀏覽器測試依賴。

依本輪要求，驗證不截圖；以 DOM、CSS 動畫／版面數值、狀態、WASD／F 與射線結果判定。測試直接使用離線 file://，不啟動伺服器。隔離測試打包正式 main、UI、狀態、控制器、射線及基礎場景，以場景替身略過 WebGL；另測完整正式場景的精細模型載入、實際移動／F 銀杯、典禮冊、宴會長桌與畫廊門入口，以及畫廊入場／返回首頁／重置，該補測暫停 WebGL draw。測試前置僅準備第一關完成前的有效狀態，不重新驗收第一關。來源雜湊與方法記於 test-results/，測試 HTML 與各步交付 HTML 快照位於系統暫存目錄。

本輪未測動畫畫質、GPU 效能或實體揚聲器。`check-v2-progress`、第一關琴鍵／領取／動畫測試與更早工具均保留歷史用途，不是第二關預設入口。

精確距離及遮擋的補充測試可用 `node tests/raycast-cases.mjs` 執行；它直接呼叫遊戲選取函式，與城堡中實際走近物件按 F 的瀏覽器測試互補。
