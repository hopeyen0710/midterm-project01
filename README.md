# 時空密室｜艾琳擁有明天

劇情 v2，更新於 2026-11-03。訪客應艾琳的求救信於 23:30 抵達城堡，與她及已故工匠學徒伊恩解開未完成的王室終典。

八幕故事對應五關：鋼琴 → 典禮冊 → 畫廊 → 人偶 → 終典。結局是艾琳獲救、伊恩散席，不是訪客接替旁白。

## 本機啟動

需要 Python 3；在專案根目錄執行：

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory game
```

開啟 <http://127.0.0.1:4173>。請使用 HTTP 伺服器，不直接雙擊 HTML；網站使用原生 JavaScript 模組，不需要安裝前端套件。

## 可操作內容與示範答案

1. 閱讀求救信，回應伊恩進入大廳。
2. 比對伊恩的錯誤記憶與音樂盒；示範正解為 `1 → 3 → 2 → 4`，第五音不屬於演奏。
3. 阻斷銀杯送水，比較有印記與無印記的燭臺反應，使用項鍊取得附件線索。
4. 示範畫像四片交換至 `1、2、3、4`；依序閱讀文件，艾琳自行撤回誓約。
5. 裝妥三個齒輪、節奏調至每分鐘 `60` 次、上發條、戴冠閉合扣環。暫停心跳觀察登記仍保留；取冠也不取消登記。
6. 沿用登記，恢復心跳、扶正王冠、接妥制動。示範事件順序為「維持穩定心跳 → 確認登記並升起鐘錘 → 報時觸發制動停心」。先試運轉，再正式推進午夜。

確切音高、片數、齒輪規格、60 次節奏與三段式選單不是新稿指定的正式答案，仍待定稿。時間隨關卡推進；閱讀與試運轉不計時。每關完成後可重讀完整劇情，結局可閱讀全八幕。

## 存檔與驚嚇

使用 `midnight-castle-story-v2` 本機存檔，不匯入也不刪除舊版進度。音效預設關閉、降低驚嚇預設開啟。驚嚇為文字遮罩與提示低音，尚未製作真人配音、角色動畫、支架或空椅完整演出。

## 檢查

需要 Node.js，可執行：

```sh
node --test tests/story-state.test.mjs
node --check game/app.js
```

測試包括無心跳不可登記、停心與取冠不解除登記、試運轉不改變實驗狀態、缺少制動不得結束，以及午夜完成判定。
